# React Todo Tracker

A standalone React + Vite Todo assignment app.

## Features
- Add, edit and delete tasks
- `Make Food 3` creates three separate `Make Food` tasks
- Every successful edit increments `updateCount`
- Completed-task toggle and clear completed
- Persistent data with localStorage
- Responsive UI

## Run
```bash
npm install
npm run dev
```

Build check:
```bash
npm run build
```
